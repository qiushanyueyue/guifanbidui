# ADR-0002：搜建筑与工标网明确状态作为运行判定依据

- status: `superseded by ADR-0003`
- date: `2026-08-25`
- owners: 项目维护者与代码代理

## 背景

生产 V2 数据库有大量由搜建筑目录确认身份、但尚未获得明确状态的 `unknown` 记录。官方来源适配器尚未全部连通，而用户明确接受工标网和搜建筑作为“现有、现行”运行判定依据。项目仍需避免把第三方网站包装成官方认证，也不能把“网站有收录”误当成“当前有效”。

## 决定

搜建筑或工标网在规范身份匹配且页面明确解析出“现行、即将实施、废止、作废、被替代、局部修订”等状态时，该单源状态可发布为 `single_source` 判定。另一来源同时确认相同规范身份且没有状态冲突时，可标记为 `cross_verified`。

只存在来源链接、目录收录、真人验证页、抓取失败或状态字段缺失时保持 `unknown/unverified`。搜建筑与工标网状态冲突时保持 `conflict`，不得按来源顺序静默覆盖。面向用户继续标明第三方来源和核验级别，正式引用仍回到发布机构原始文件。

普通搜索继续数据库-only；第三方访问只发生在显式同步、核验脚本或人工打开来源链接时。

## 替代方案

- 只有官方来源才能判现行：准确性边界最严，但现阶段官方适配器覆盖不足，无法满足可用性要求，未采用。
- 只要搜建筑或工标网有收录就默认现行：会把仍可查询的废止旧规范误判为现行，未采用。
- 工标网永远覆盖搜建筑：会掩盖第三方冲突，未采用。

## 后果

优点：可在保持来源可追溯的前提下逐批减少 `unknown`；用户能直接查看判定依据。代价：结果是第三方查新结论而非官方认证，页面结构或内容错误可能影响状态，因此必须保留来源、核验时间、失败和冲突。

## 复核条件

官方来源达到稳定覆盖、任一第三方站点改变状态语义/访问方式、第三方误判率不可接受，或产品决定恢复“仅官方可判现行”时重新评估。

本决定中“普通搜索继续数据库-only”已由 [`ADR-0003`](ADR-0003-decisive-freshness-aware-verification.md) 取代；第三方明确状态证据的可追溯要求继续有效。
